# Site Estático - Proposta PGL para BID Onesubsea

Este repositório contém os arquivos para um site estático simples, criado como parte da proposta da PGL para o BID da Onesubsea. O site foi desenvolvido com HTML, CSS e um SVG para o mapa de fundo, otimizado para fácil publicação no GitHub Pages.

## Conteúdo

- `index.html`: O arquivo principal da página web.
- `css/styles.css`: A folha de estilos que define a aparência do site.
- `images/world-map-bg.svg`: A imagem vetorial do mapa mundi usada no fundo da seção inicial.
- `pdfs/`: Pasta contendo as propostas técnica e comercial em formato PDF.
  - `Proposta_Tecnica_PGL_Onesubsea.pdf`
  - `Proposta_Comercial_PGL_Onesubsea.pdf`

## Visualização

Você pode visualizar o site abrindo o arquivo `index.html` diretamente em seu navegador web.

## Publicação no GitHub Pages

Para publicar este site no GitHub Pages, siga estes passos simples:

1.  **Crie um Repositório no GitHub:** Se ainda não tiver um, crie um novo repositório no GitHub para hospedar os arquivos do site. Você pode nomeá-lo como `seu-usuario.github.io` para um site de usuário/organização ou qualquer outro nome para um site de projeto.
2.  **Faça o Upload dos Arquivos:** Envie todos os arquivos e pastas (`index.html`, `css/`, `images/`, `pdfs/`) para a raiz do seu repositório GitHub.
3.  **Habilite o GitHub Pages:**
    - Vá para as configurações (`Settings`) do seu repositório no GitHub.
    - Role para baixo até a seção "GitHub Pages".
    - Em "Source", selecione o branch onde você fez o upload dos arquivos (geralmente `main` ou `master`).
    - Selecione a pasta `/root` (raiz).
    - Clique em "Save".
4.  **Acesse o Site:** Após alguns minutos, seu site estará disponível no endereço fornecido pelo GitHub Pages (algo como `https://seu-usuario.github.io/nome-do-repositorio/` ou `https://seu-usuario.github.io/` se for um site de usuário).

## Observações

- Este é um site estático puro. Não requer build ou instalação de dependências.
- O espaço para a logo no cabeçalho (`logo-placeholder`) é um marcador. Você precisará editar o `index.html` para inserir a imagem da sua logo.
- O mapa mundi é uma representação simplificada e estática.
